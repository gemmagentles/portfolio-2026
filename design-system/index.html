Typography

Text is set with a short list of text styles, named by their job. To style some text, pick the style that describes what it is (a card title, a caption), not a size: @include type(card-title);. Each style sets the font, size, weight, line height, letter spacing and capitals together.

Rules

  • Components don't set font sizes, fonts, weights, line heights, letter spacing or capitals; the text style does. They only set colour and spacing.
  • The h1, h2 and h3 tags, .lead and .eyebrow already have their style, and everything else gets body. Add a style only when the text does a different job from its tag.
  • Bold is the only variation: @include type(body, $bold: true); for buttons and emphasis.
  • If nothing fits, add a style to the list (src/scss/abstracts/_type.scss and this page) rather than a one-off size.
  • Exceptions, each marked "Type exception" in the code: decoration (the giant outlined words), words sized to fit the screen (the hero and Work page titles, tool names), miniatures inside pictures (device and browser mock-ups, brand boards) and the logo.

Shape, motion & layout

Corners

  • 8pxScreens, browser frames
  • 12px--radius
  • 16pxCards, role tiles
  • PillButtons, tags, the nav

Motion

--ease-out
cubic-bezier(0.22, 1, 0.36, 1). The default: scroll reveals, the carousel, footer and process hovers.
Springy
cubic-bezier(0.34, 1.4, 0.64, 1). The white pill gliding between header links, overshooting a little.
Ease in and out
cubic-bezier(0.65, 0, 0.35, 1) for the "Repo private" padlock; plain ease-in-out for colour fades and hover fills, 0.3 to 0.45s.
Reduced motion
Every animation is wrapped (the motion-ok mixin) so it only runs for visitors who haven't asked for less motion; they see the finished state.
